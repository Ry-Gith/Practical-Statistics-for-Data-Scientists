## Deskripsi

Repository ini membahas Chapter 1 sampai Chapter 7 dengan menggunakan Python dan Jupyter Notebook.

## Chapter yang Dibahas

### Chapter 1 - Exploratory Data Analysis

Chapter ini membahas Exploratory Data Analysis (EDA), yaitu proses memahami
karakteristik data sebelum dilakukan analisis lebih lanjut.

Materi meliputi:
- struktur data
- data frame
- mean dan median
- ukuran variabilitas
- percentile
- boxplot
- histogram
- density plot
- data kategorikal
- correlation
- scatterplot
- visualisasi beberapa variabel

### Chapter 2 - Data and Sampling Distributions

Chapter ini membahas sampling, sample bias, sampling distribution,
Central Limit Theorem, bootstrap, confidence interval, dan berbagai
jenis distribusi probabilitas.

Materi meliputi:
- random sampling
- sample bias
- selection bias
- sample mean
- regression to the mean
- sampling distribution
- Central Limit Theorem
- standard error
- bootstrap
- confidence interval
- normal distribution
- t-distribution
- binomial distribution
- chi-square distribution
- F-distribution
- Poisson distribution
- exponential distribution
- Weibull distribution

### Chapter 3 - Statistical Experiments and Significance Testing

Chapter ini membahas eksperimen statistik dan pengujian signifikansi.

Materi meliputi:
- A/B testing
- control group
- hypothesis testing
- null hypothesis
- alternative hypothesis
- permutation test
- p-value
- statistical significance
- Type I dan Type II error
- t-test
- multiple testing
- ANOVA
- chi-square test
- Fisher's exact test
- multi-arm bandit
- power dan sample size

### Chapter 4 - Regression and Prediction

Chapter ini membahas regresi sebagai metode untuk menjelaskan hubungan
antarvariabel dan membuat prediksi.

Materi meliputi:
- simple linear regression
- regression equation
- fitted values
- residual
- least squares
- multiple linear regression
- cross-validation
- model selection
- weighted regression
- prediction
- confidence interval
- prediction interval
- dummy variables
- factor variables
- multicollinearity
- confounding variables
- interaction
- regression diagnostics
- outlier
- influential values
- heteroskedasticity
- polynomial regression
- spline regression
- generalized additive models

### Chapter 5 - Classification

Chapter ini membahas metode klasifikasi untuk memprediksi variabel target kategorikal.

Materi meliputi:
- Naive Bayes classification
- Discriminant Analysis (LDA & QDA)
- Logistic Regression dan logit link function
- odds ratio dan Maximum Likelihood Estimation
- evaluasi model klasifikasi (confusion matrix, precision, recall, specificity, ROC, AUC, lift)
- strategi imbalanced data (oversampling, undersampling, class weight)

### Chapter 6 - Statistical Machine Learning

Chapter ini membahas metode Machine Learning berbasis statistik untuk tugas klasifikasi dan regresi non-parametrik.

Materi meliputi:
- K-Nearest Neighbors (KNN) dan metrik jarak
- Decision Trees, Gini Impurity, Entropy, dan pruning
- Bagging dan Random Forests
- Variable Importance (Gini Importance)
- Boosting (Gradient Boosting / XGBoost)

### Chapter 7 - Unsupervised Learning

Chapter ini membahas metode Unsupervised Learning untuk menemukan struktur dan kelompok tersembunyi pada data tanpa label.

Materi meliputi:
- Principal Components Analysis (PCA) dan Scree Plot
- K-Means Clustering, Elbow Method, dan Silhouette Score
- Hierarchical Clustering dan Dendrogram
- Model-Based Clustering (Gaussian Mixture Models / GMM)
- Scaling dan pemrosesan variabel kategorikal dalam clustering

## Tujuan

Tujuan repository ini adalah memahami konsep statistik yang digunakan dalam data science melalui implementasi Python, visualisasi, eksperimen, serta interpretasi hasil.
